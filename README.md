# Домашнее задание 10.1
Программа разработана на Python для сортировки банковских операций
## Установка
1. Клонируйте репозиторий:
```
git clone https://github.com/Soldattt/home_prj.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование программы
1. В модуле *main.py* удалите коментирующие символы (#) в начале каждой из строк
2. Вставьте в строку вызова функции *filter_by_state()* необходимый список, например:
```
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
3. Таким же образом вставьте в строку вызова функции *sort_by_date()* необходимый список, для примера можно взять из предидущего пункта
4. Произведите запуск программы на кнопку **Run** и наслаждайтесь)

### Тестирование работы функций
Произведено тестирование работы функций, все тесты находятся в папке *tests*, отчет о покрытии тестами можно посмотреть в папке *htmlcov*, а также вызвав следующую команду:
```
pytest --cov
```
